### 1. Descripción del Problema (Mi Idea Original)
Este programa resuelve el problema de calcular el promedio final de un estudiante de la UEA con 3 notas. En la UEA se aprueba con 7.0, por eso el programa debe decir si el estudiante esta APROBADO o REPROBADO.

### 2. Solución Técnica
- Defino la función con def calcular_promedio(nota1, nota2, nota3):
- La función recibe 3 parámetros: nota1, nota2, nota3
- Dentro calculo el promedio y lo regreso con return
- En el programa principal pido las 3 notas al usuario
- Hago la llamada a la función y guardo el resultado
- Con print muestro el promedio y el nombre del estudiante

### 3. Cómo Ejecutar el Programa
python promedio.uea.py
